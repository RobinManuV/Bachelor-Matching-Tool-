# Informar de un problema de seguridad

No publiques credenciales, datos personales ni una vulnerabilidad sin corregir en una incidencia o pull request pública. Usa la función de reporte privado de vulnerabilidades de GitHub si está habilitada para este repositorio, o escribe a [hello@project-robin.com](mailto:hello@project-robin.com) indicando el repositorio, commit o ruta afectada, impacto y pasos para reproducirla.

No pruebes contra cuentas, registros de clientes o servicios de producción sin autorización escrita. Este documento no promete un plazo de respuesta ni un programa de recompensas.
